# How I Write My Articles with HTML & Markdown

If you have ever wondered how this blog works behind the scenes, it runs on a combination of clean HTML, JavaScript, and pure Markdown. I designed it this way so I can focus purely on writing without having to copy and paste HTML boilerplate for every single post.

Here is a straightforward breakdown of how the whole system is put together.

### The Core Component

The engine driving the blog is a web component called <a href="https://zerodevx.github.io/zero-md/">zero-md</a>. It is a lightweight script that takes a standard Markdown file and automatically renders it as HTML directly in the browser.

### Step 1: Writing the Markdown

Whenever I want to write a new post, I simply create a `.md` file. I save it into a categorized folder, like `articles/about website/10-27-24.md`.

Inside that file, it is just standard Markdown text. There are no `<html>`, `<head>`, or `<body>` tags required. It is completely clean and minimalist.

### Step 2: The Article Hub

Instead of making a brand new HTML page for every article, everything is routed through one main file: `blog.html`.

Inside this file, there is a JavaScript array called `articlesRaw`. To publish a new post, I just add a new block of information to this list. It looks like this:

```javascript
const articlesRaw = [
  {
    title: "How I write my articles with HTML & Markdown?",
    description: "Within this article I talk about how through a script I found online I write my articles with HTML and Markdown.",
    date: "October 27, 2024",
    tag: "about",
    path: "articles/about website/10-27-24.md"
  }
];
```

The system uses this array to automatically generate the grid of article cards you see on the main blog page[cite: 1].

# Step 3: The Reading Modal
When you click on one of those article cards, it does not load a new webpage[cite: 1]. Instead, a sleek overlay modal pops up on the screen[cite: 1].

Inside that modal is a single <zero-md> tag[cite: 1]. The HTML looks something like this:

```html
<div class="modal-overlay" id="modalOverlay">
  <div class="modal-content">
    <div class="modal-body">
      <zero-md id="modalMarkdown" src="">
        <template>
          <style>
            .markdown-body { font-family: inherit !important; word-wrap: break-word !important; }
            .markdown-body pre { background-color: #1e1e1e !important; border: 1px solid #333 !important; border-radius: 8px !important; }
            /* Custom styling for the text goes here */
          </style>
        </template>
      </zero-md>
    </div>
  </div>
</div>
```

The JavaScript takes the path from the array and inserts it right into the src="" attribute of that tag[cite: 1]. The script instantly fetches the Markdown file and displays it inside the popup window[cite: 1]. The `<template>` block ensures all the text, code blocks, and links perfectly match the minimalist design of the site[cite: 1].

This setup keeps everything incredibly simple. I can manage all my articles from one central list, and the reader gets a fast, seamless experience without constant page reloads.
